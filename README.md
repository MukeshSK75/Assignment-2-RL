# 🎮 Grid World Reinforcement Learning Game

## 📌 Overview
This project demonstrates a simple Reinforcement Learning agent that learns to reach a goal while avoiding penalties.

## 🎯 Objective
- Reach Goal → +10 reward
- Avoid Penalties → -10 penalty
- Minimize steps → -1 per move

## 🧠 Algorithm
Q-Learning (model-free RL)

## 📊 Environment
4x4 grid:
- Start: (0,0)
- Goal: (3,3)
- Penalties: multiple positions

## ▶️ Run
```bash
python gridworld_qlearning.py
